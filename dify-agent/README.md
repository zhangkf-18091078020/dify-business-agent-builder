# 本目录：`dify-agent/`（本 Skill 仓内）

能力包**不是**最终产物（最终产物在 Dify：Tool + Skill + Agents）。  
本目录用于：

1. **临时落盘**：探查/反推后先写 `〈名〉-业务能力包.md`（或公共包），人确认矩阵后再按 `01`～`04` 造物。  
2. **回退读取**：原流程（Dify 取模块 / 页面探查）**扒不到**对应业务流程时，从这里读已有技能包再搭。

## 白名单（同 `rules/04` §5）

```text
dify-agent/
├── README.md
└── 〈业务名〉-业务能力包.md    # 或 〈名〉-公共能力包.md
```

禁止再放：ops Skill 正文、Agent 短提示词、执行报告、`build/`、临时脚本。

## 命名与模板

- 业务：`templates/业务能力包模板.md` → `对象采集-业务能力包.md` / `数据比对-业务能力包.md`  
- 公共：`templates/公共能力包模板.md` → `监控-公共能力包.md`  
- 样板参考：`examples/`（非运行时必须）
