## 2. 页面同款接口表（自 Dify Workflow / Chatflow 反推）

> **路径写法**：表中路径须反引号 + **以 `/` 开头**（含上下文根）。  
> **Dify HTTP 节点 url**：`{{#env.ESI_COMPARE_API_BASE#}}` + 表路径中去掉重复上下文后的后缀，或写死绝对 `http(s)://…`。推荐环境变量见 §5.1。  
> 禁止把 `` `/esi_compare/...` `` 原样写入节点 url。

鉴权：Workflow 内登录取 `tokenID`（禁止写进 Skill / Agent 提示词；禁止向用户要 token）。有 `DEFAULT_TOKEN` 时可短路，不必每次打登录接口。

| 步骤 | Method | 路径 | 关键表单字段 | 成功判定 | 创建图节点角色 |
|------|--------|------|--------------|----------|--------------|
| 登录 | POST | `/esi_permission/serviceByUserInfo/validateUser.do` | account / pwd（encrypt）等 | 解析出 token | Code「准备参数」内或独立 HTTP（可短路 DEFAULT_TOKEN） |
| **列表** | POST | `/esi_compare/OpCompareInfoController/getAllOpCompareJob.do` | tokenID；可选过滤 | 业务成功码；Markdown 表 | 列表工具可用 Code；创建失败回查可复用 |
| **部署** | POST | `/esi_compare/AutoDeployController/deployBatch.do` | `tokenID`、`jsonArray` | `code` 成功且 `data.success` 有任务名 | **HTTP**（禁止折进大 Code） |
| **启动** | POST | `/esi_compare/AutoDeployController/startStopByFlowName.do` | `tokenID`、`流程name`、`operateFlag=start` | 提交成功（≠比对完成） | **HTTP** |
| **查比对状态** | POST | `/esi_compare/AutoDeployController/getCompareStatusByFlowName.do` | `tokenID`、`流程name` | `compareStatus` / `compareResult` | **HTTP** |
| 停止 | POST | 同上 startStop | `operateFlag=stop` | 暂缓独立工具 | — |
| 删除 | POST | `/esi_compare/AutoDeployController/deleteByFlowName.do` | `流程name` 等 | 暂缓 | — |

### 2.1 列表工具入参（`list_esi_compare`）

| 参数 | 说明 | 默认 |
|------|------|------|
| `job_name` | 任务名模糊 | 空 |
| `limit` | 条数 | 10 |
| `offset` | **行偏移** | 0 |
| `mac_id` / `db_id` | 过滤 | 空 |
| `result` | 比对结果过滤 | 空 |

列表状态文案：`0` 尚未比对 / `1` 暂停比对 / `2` 正在比对 / `3` 比对成功 / `4` 比对失败。

### 2.2 创建工具入参（`create_esi_compare_task`）

| 参数 | 说明 | 默认 |
|------|------|------|
| `job_name` | 任务名可选；多条时自动加后缀 | 空 → `cmp_case_<salt>_<i>` |
| `count` | 条数 | 1（钳制 1～10） |
| `source_host_name` / `target_host_name` | 主机名 | `5.250_xcmp_root`（目标未给则同主机） |
| `source_db_name` / `target_db_name` | 数据源名 | `yuands_239_ds` / `yuandt_239_dt` |
| `src_schema` / `src_table` / `tar_schema` / `tar_table` | 表映射 | `yuands` / `yuan_xcmp_sync_2` → `yuandt` / `yuan_xcmp_sync_2` |

`deployBatch` 的 `jsonArray` 由「准备参数」Code 节点生成。

### 2.3 创建 Workflow 编排拓扑（富图；强制）

对齐 `rules/01` §2.1 与对象采集创建任务形态。**创建类禁止** `Start → 单 Code → End`。

```text
开始（入参见 §2.2）
 → [IF] 参数合法?（count 1～10；拒占位任务名）
      ├ 否 → [Code] 拒绝占位/非法参数 → 合并输出 → 结束
      └ 是 → [Code] 准备参数（token 短路/登录 + 拼 jsonArray + 任务名列表）
           → [HTTP] 部署 deployBatch
           → [IF] 部署成功?
                ├ 否 → [Code] 汇总失败（failed_step=部署）→ 合并输出 → 结束
                └ 是 → [HTTP] 启动 startStop(start)（按部署成功名；多条可串或循环策略见下）
                     → [IF] 启动提交成功?
                          ├ 否 → [Code] 汇总失败（已部署名 + failed_step=启动）→ 合并输出 → 结束
                          └ 是 → [Code] 等待约 12s
                               → [HTTP] 查状态 getCompareStatus
                               → [Code] 合并输出（成功/部分成功）→ 结束
```

| 约定 | 说明 |
|------|------|
| 克隆源 | 优先深拷 **对象采集创建任务** 富图 `graph`，只改 Start 变量、Code、HTTP url/body、IF 条件与汇总文案 |
| HTTP url | 绝对 `http(s)://` 或 `{{#env.ESI_COMPARE_API_BASE#}}/AutoDeployController/...`（基址无尾斜杠且已含或不含上下文根时须与路径拼接一致） |
| 多条 count>1 | 准备参数一次生成多任务 `jsonArray`；启动/查状态按成功名逐个（Code 循环或串行 HTTP）；任一条启动失败记入汇总，不抹掉已部署名 |
| 列表工具 | 允许 `Start→Code→End`（简单图） |
| 输出 | End 输出单一可读 `result`（Markdown）；含是否成功、失败步骤、任务名、状态原文 |

## 4. 状态机与异步

| 项 | 说明 |
|----|------|
| 列表 `jobStatus` | 0～4 见 §2.1 |
| 提交成功 vs 比对完成 | `startStop` 成功仅表示提交；须 `getCompareStatus` |
| 轮询 | 创建链路固定等待约 12s 一次查询；非无限轮询 |
| 超时话术 | 以工具汇总为准；可提示稍后列表/再查 |

### 4.1 创建半失败

| 项 | 约定 |
|----|------|
| 部署失败 | 输出原因，**不得**继续 start |
| 已部署后失败 | 报告已部署任务名 + `failed_step`；禁止静默删 |
| 回查 | 有任务名时可列表按名回查；有记录=partial |
| 工具输出 | 建议含 success/partial、failed_step、任务名、状态、下一步提示 |

## 9.1 规则覆盖（相对 L1）

| 覆盖项 ID | 覆盖的公共规则（简述） | 本包取值 | 原因 |
|-----------|------------------------|----------|------|
| C-CMP-1 | 列表分页默认 | `offset` 默认 **0**（行偏移），不是对象采集的页码从 1 | 现网列表工具已如此 |
| C-CMP-2 | 创建类是否自动启动 | **搭建 = 部署后自动 start + 查状态**（非仅保存） | 对齐 Chatflow / Skill |
| C-CMP-3 | 创建类图形态 | **禁止** `Start→单 Code→End`；须 HTTP+IF 分步（§2.3）；克隆对象采集创建富图改 url/body | 与对象采集创建可读性对齐 |
| C-CMP-4 | 环境常量 | 基址等进 `ESI_COMPARE_*` / `ESI_PERM_*` 环境变量；HTTP 优先 `{{#env…}}` | 换环境不改节点 |
