## 1. 能力矩阵

| 用户意图（说法） | 工具名（英文蛇形） | 对齐页面能力 / 现网资产 | 用户已确认 |
|------------------|--------------------|-------------------------|------------|
| 列表 / 有哪些比对任务 | `list_esi_compare` | Workflow 工具「数据比对列表查询」；默认 limit=10，offset 默认 **0**（行偏移，≠对象采集页码） | **是**（现网已挂） |
| 搭建 / 部署 / 创建比对任务 | `create_esi_compare_task` | Workflow「数据比对创建任务」：`deployBatch` → `startStop(start)` → 等待约 12s → `getCompareStatus`（对齐 Chatflow 搭建） | **是**（现网已挂） |
| 单独启动 / 停止 / 查单任务状态 | （独立 Tool **暂缓**） | Chatflow 有 `startStop` / `getCompareStatus`；Agent 短提示曾写「暂缓」，但 **创建工具链路内已含启动+查状态** | **否**（未独立上线） |
| 销毁 / 删除 | （独立 Tool **暂缓**） | Chatflow 有 `deleteByFlowName`；Agent / Skill 明确告知暂缓 | **否** |

拆分提醒：列表 ≠ 单条状态；现网「查状态」仅作为创建链路尾步，不是独立 `operate_*`。禁止把「搭建」理解成只 deploy 不 start（Skill：禁止只部署不启动）。

## 2. 页面同款接口表（自 Dify Workflow / Chatflow 反推）

鉴权：Workflow 内登录 `serviceByUserInfo/validateUser.do` 取 `tokenID`（禁止写进 Skill / Agent 提示词；禁止向用户要 token）。

| 步骤 | Method | 路径（相对比对基址 `…/esi_compare/`，除非注明） | 关键表单字段 | 成功判定 |
|------|--------|--------------------------------------------------|--------------|----------|
| 登录 | POST | `…/esi_permission/serviceByUserInfo/validateUser.do` | account / pwd（encrypt）等；工具内置 | 解析出 token |
| **列表** | POST | `OpCompareInfoController/getAllOpCompareJob.do` | tokenID；可选 job 名模糊、limit、offset、macId、dbId、result 过滤 | 业务成功码（如 `000000`/`200`）；输出 Markdown 表 |
| **部署** | POST | `AutoDeployController/deployBatch.do` | `tokenID`、`jsonArray`（任务数组 JSON 字符串） | `code` 成功且 `data.success` 有任务名 |
| **启动** | POST | `AutoDeployController/startStopByFlowName.do` | `tokenID`、`流程name`、`operateFlag=start` | 提交成功（异步；≠比对已完成） |
| **查比对状态** | POST | `AutoDeployController/getCompareStatusByFlowName.do` | `tokenID`、`流程name` | 读 `compareStatus` / `compareResult` |
| 停止（Chatflow 有；Agent 未挂独立工具） | POST | `AutoDeployController/startStopByFlowName.do` | `operateFlag=stop` 等 | 暂缓 |
| 删除（Chatflow 有；Agent 未挂独立工具） | POST | `AutoDeployController/deleteByFlowName.do` | `流程name` 等 | 暂缓 |

### 2.1 列表工具入参（`list_esi_compare`）

| 参数 | 说明 | 默认 |
|------|------|------|
| `job_name` | 任务名模糊 | 空 |
| `limit` | 条数 | 10 |
| `offset` | **行偏移** | 0 |
| `mac_id` / `db_id` | 过滤 | 空 |
| `result` | 比对结果过滤 | 空 |

列表状态文案（工具内映射）：`0` 尚未比对 / `1` 暂停比对 / `2` 正在比对 / `3` 比对成功 / `4` 比对失败。

### 2.2 创建工具入参（`create_esi_compare_task`）

| 参数 | 说明 | 默认（现网 Workflow） |
|------|------|------------------------|
| `job_name` | 任务名可选；多条时自动加后缀 | 空 → `cmp_case_<salt>_<i>` |
| `count` | 条数 | 1（钳制 1～10） |
| `source_host_name` / `target_host_name` | 主机名 | 默认主机 `5.250_xcmp_root`（目标未给则同主机） |
| `source_db_name` / `target_db_name` | 数据源名 | `yuands_239_ds` / `yuandt_239_dt` |
| `src_schema` / `src_table` / `tar_schema` / `tar_table` | 表映射 | `yuands` / `yuan_xcmp_sync_2` → `yuandt` / `yuan_xcmp_sync_2` |

`deployBatch` 的 `jsonArray` 由「准备参数」节点生成；字段名以 Workflow 为准，禁止臆造。

## 3. 创建类落库硬约束

| 项 | 要求 | 已确认 |
|----|------|--------|
| 部署载荷字段 | 必须为 `jsonArray`（字符串化任务数组） | 是（现网节点） |
| 启动主键 | 使用 `流程name`（部署成功名） | 是 |
| 条数上限 | 1～10；超出钳制 | 是 |

| Agent 文案 vs 工具 | **以 Skill + 创建 Workflow 为准**（搭建含启动+查状态）；短提示若仍写 `autoStart=false` 应在核对/补齐时改掉 | 是 |

## 4. 状态机与异步

| 项 | 说明 |
|----|------|
| 列表 `jobStatus` | 0～4 见 §2.1 |
| 提交成功 vs 比对完成 | `startStop` 成功仅表示提交；须 `getCompareStatus`（创建链路内等待约 12s 再查） |
| 轮询 | 现网创建工具固定 sleep 12s 一次查询；非无限轮询 |
| 超时话术 | 以工具汇总为准；可提示稍后列表/再查 |

### 4.1 创建半失败

部署失败 → 输出失败原因，**不得**继续 start。部署成功但 start/查状态异常 → 报告已部署任务名 + 失败步骤；禁止静默删。
