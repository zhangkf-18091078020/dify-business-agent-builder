# 说明与操作手册（给人看）

---

## 1. 这个项目是什么

共享 **Agent Skill 包**：指导 Cursor / Claude Code / Codex 等在云澜 Dify 上搭：

- 业务 Agent（对象采集、应用采集…）
- 公共 Agent（监控、告警…；须打标签并登记目录）

远端：

```text
http://192.168.1.174:3000/zhangkefan/dify-business-agent-builder.git
```

## 3. 出了问题改哪个文件

| 现象 | 改 |
|------|----|
| 工作流 / 空壳 | `01-Workflow规范.md` |
| 发布为工具 | `02-Tool规范.md` |
| Dify Skill 正文/路由 | `03-Skill规范.md` |
| 旧版 Agent / Agents 形态 | `04-Agent规范.md` |
| 总流程、业务 vs 公共 | `SKILL.md` |
| 验收 / 禁止项 | `生成契约.md` |
| 某一业务做什么 | `〈业务〉-业务能力包.md`（L3） |
| 公共已上线登记 | `公共能力目录.md` |
| 安装方式 / URL | `docs/INSTALL.md` |
| 协作 FAQ | `docs/使用说明.md`（本文件） |

优先级：`L3 > L2 > L1`；碰 L0 停问（见契约）。
