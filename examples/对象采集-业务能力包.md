## 2. 页面同款接口表（摘要）

| 步骤 | Method | 路径（相对业务基址 `…/esi_migration`） | 关键表单字段 | 成功判定 |
|------|--------|------------------------------------------|--------------|----------|
| **列表** | POST | `/gather/gatherList` | `offset`=页码（首页 `1`）、`limit`（默认 10）、可选 `flowName`/`flowStatus`/`macId`/`dbId`；服务端 `flowType=1` | 业务 `code=000000` |
| 保存流程 | POST | `/objCollectController/saveCMFlowInfo` | 与页面一致 | 同上 |
| 保存配置 | POST | `/objCollectController/saveConfig` | `tokenID`、`flowId`、**`dataJson`** | 同上 |
| 完成校验 | POST | `/objMigrationController/startAuto` | 与页面一致 | 同上 |
| 启停操作 | POST | `/gather/operate` | `tokenID`、`flowId` 等 | 同上 |
| 查详情（单任务状态） | POST | `/gather/findById` | `flowId` | 同上 |

完整字段以专篇与抓包为准。

## 3. 创建类落库硬约束

| 项 | 要求 | 已确认 |
|----|------|--------|
| 配置提交字段名 | 必须为 `dataJson`（非其他命名） | 是 |
| `detailConfig` | 禁止空对象 `{}`；样板默认含 `run_mode=d,0` | 是 |
| objType | 含 `flowId`、`objTypeId`、`isSelect=1` | 是 |
| mapping | 含 `flowId`、目标资源、`isSelect=1` | 是 |

未满足时：页面创建任务可启动，Agent 创建任务易出现主机侧配置缺失（如 DAS-100）。

## 4. 状态机与异步

| 项 | 说明 |
|----|------|
| 提交成功 vs 状态已推进 | `gather/operate` 返回成功仅表示提交；须查询/有限轮询确认状态 |
| 轮询 | 有上限；超时提示稍后查询，禁止无限等待 |
| 销毁 | `destroy_mode`：`keep` / `now` / `after` 等，须符合状态机 |

### 4.1 创建半失败（搭 Agent）

创建任一步失败 / 超时 / killed，都不能推断库中无数据。须按 `flow_name` 回查：有记录 → partial（失败步骤 + 状态 + 已入库）；无记录才报未落库。禁止静默删、禁止未确认覆盖。

## 5. 默认环境与可覆盖参数

| 参数 | 默认值（样板） | 是否允许覆盖 |
|------|----------------|--------------|
| mac_id | 样板默认主机 ID | 是 |
| db_id | 样板默认数据源 ID | 是 |
| mapping | 如 `wangqds` | 是 |
| target_db_types | 如 gaussdb 系列 | 是 |
| destroy_mode | `keep` | 是 |
| run_mode | `d,0` | 是 |
| obj_types | TABLE,VIEW | 是 |

用户给主机名/数据源名时：先公共解析，再覆盖 ID。

## 7. 危险操作

| 操作 | 是否需二次确认 | 说明 |
|------|----------------|------|
| 销毁 / 删除 | 是 | 用户同句已明确确认除外；**必须带可定位的流程名** |

### 7.1 销毁缺流程名

未带流程名时禁止空参销毁。本会话刚创建 → 复述该名并确认；否则追问流程名。

## 8. 验收用例

| 编号 | 用例 | 期望 |
|------|------|------|
| T1 | 未指定主机创建 | 默认资产；返回流程标识与落款 |
| T2 | 指定主机名/数据源名创建 | 先 `resolve_asset` 再创建 |
| T3 | 查询状态 | 真实状态文案 |
| T4 | 启动后查询 | 可区分提交成功与状态推进 |
| T5 | 统计 | 结构化关键字段 |
| T6 | 销毁（已带名+确认） | 执行销毁 |
| T6b | 只说「销毁」未带名 | 追问或确认本会话刚创建；不空参调用 |
| T7 | 创建失败/超时 | 先回查；有则 partial，无才报未落库 |
