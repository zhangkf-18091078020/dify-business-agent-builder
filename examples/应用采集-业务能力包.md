## 2. 页面同款接口表

业务基址：`http://10.0.0.222:9996/esi_migration/`  
鉴权：`tokenID` / `Admin-Token`

| 步骤 | Method | 路径 | 关键表单字段 | 成功判定 |
|------|--------|------|--------------|----------|
| 列表 | POST | `/appGather/gatherList` | `offset`（首页 `1`）、`limit`、可选 `flowName`；服务端强制 `flowType=3` | `code=000000` |
| 状态汇总 | POST | `/appGather/statusList` | 可选 `macId`/`dbId` | 同上 |
| 查详情 | POST | `/appGather/findById` | `flowId` | 同上 |
| 启停 | POST | `/appGather/operate` | `flowId`（按 `flowStatus` 状态机切换） | 同上 |
| 删除 | POST | `/objCollectController/delete` | `tokenID`、`flowId` | 同上 |
| 保存流程 | POST | `/objCollectController/saveCMFlowInfo` | `flowType=3`、`macId`、`dbId`、`reserve2` 等 | 同上 |
| 保存配置 | POST | `/objCollectController/saveConfig` | `tokenID`、`flowId`、**`dataJson`** | 同上 |
| 完成校验 | POST | `/objMigrationController/startAuto` | `isUpload=1`、`isConfig=1` | 同上 |
| 基础信息 | POST | `/view/objectMessageView` | `flowId` | 同上 |
| 对象分布 | POST | `/view/objectBarView` | `flowId` | 同上 |
| 评估概况 | POST | `/view/AnalysisOverview` | `flowId`、`serviceName` | 同上 |

## 3. 创建类落库硬约束

| 项 | 要求 | 已确认 |
|----|------|--------|
| 配置提交字段名 | `dataJson` | 是（对齐对象采集 + 创建自测通过） |
| `detailConfig` | 禁止空 `{}`；默认 `run_mode=d,0` | 是 |
| objType | 含 `flowId`、`objTypeId`、`isSelect=1` | 是 |
| mapping | 含 `flowId`、目标资源、`isSelect=1` | 是 |
| flowType | 必须为 `3` | 是 |

## 4. 状态机与异步

| 项 | 说明 |
|----|------|
| 状态枚举 | `0`待开始 `1`采集中 `2`采集停止 `3`采集异常 `4`解析中 `5`解析停止 `6`解析异常 `7`评估中 `8`评估停止 `9`评估异常 `10`已完成 |
| 提交成功 vs 状态已推进 | `appGather/operate` 成功仅表示提交；须查询确认 |
| 销毁 | 运行中（1/4/7）需先停再删；`destroy_mode`：`keep`/`now`/`after`（创建工具对 now/after 引导走 operate destroy，避免沙箱超时） |
