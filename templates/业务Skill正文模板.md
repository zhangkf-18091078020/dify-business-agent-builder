## 路由

| 用户意图 | 动作 |
|----------|------|
| 查看列表 / 有哪些任务 | 调 `list_…`；带过滤则透传 |
| 搭建 / 部署 / 创建 | 调 `create_…`；**（写明是否必须 start+查状态）** |
| 话里有主机名/数据源名 | 先 `resolve_asset`，**同一轮**再调业务工具；禁止只回解析结果 |
| 未提资产名 | 直接业务工具 + 上表默认 |
| 销毁 / 删除 | （有工具则确认带名；无则明确暂缓） |

## 安全与确认

- 会写库/会启动的操作：…  
- 销毁：须任务名 + 确认（同句已明确除外）

## 回复与执行

- 中文；先结论；优先工具原文；禁止长思考。  
- 已具备业务意图 → **立刻调工具**，禁止先检查「Skill/工具是否挂载」。  
- 未完成业务意图前，禁止把「解析成功」当最终回复。

## 创建半失败

失败/超时/killed → 按流程名回查；有记录则说明已入库+失败步骤；无记录才说未落库。禁止未确认销毁。
