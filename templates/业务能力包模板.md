## 1. 能力矩阵

> 能力来自**环境页面**（按钮/Tab/列表/详情等），不是来自「创建+启停+统计」假设。  
> 有列表页则默认带「查看列表」（`list_<biz>`，默认 10 条可过滤），与单条状态分开。  
> 未勾选 / 未确认的不要进矩阵、不要建工具；无入口 → 第 9 节 + 停问，禁止空壳。

| 用户意图（说法） | 工具名（英文蛇形） | 对齐页面能力 / 按钮 | 页面入口（菜单/URL/Tab） | 用户已确认 |
|------------------|--------------------|---------------------|--------------------------|------------|
| 列表 / 有哪些任务（建议默认） | `list_<biz>` | 列表页；默认 limit=10，按用户条件过滤 | | 是 / 否 |
| | | | | 是 / 否 |

拆分规则提醒：列表 ≠ 单条状态（列表走 List 接口，状态走 findById/详情）；若同时有创建与启停，宜分工具；统计若存在则独立；禁止单工具长等待全生命周期。
