# 公共能力包：〈中文名，如 监控〉

> **谁用**：监控 / 告警 / 调度 / 资产等**平台同事**，与业务采集同事共用同一套搭建 Skill（`01`～`04`）。  
> **产物归属**：Tool、Skill、Agent 均为**公共资产**；业务同事在 Dify **Agents** 顶栏能直接看到并使用该 Agent，也可在业务 Agent 上绑定本包工具/Skill。  
> **发现能力**：见 `SKILL.md`——**Dify 已有对应模块（如 Chatflow）则从模块反推落盘（禁止浏览器再抓接口）**；无模块再上平台环境汇总确认；都摸不到才模板回退。

| 项 | 值 |
|----|-----|
| 包类型 | **公共** |
| 能力 ID | 〈如 monitor〉 |
| 文档状态 | 草稿 / 待审 / 已审定 |
| 默认环境 | 〈如 222〉 |
| 页面入口 | 〈监控平台菜单/URL〉 |

| 维护方 | 〈监控平台同事 / 团队〉 |
| 起草方式 | Dify 模块反推 + 人确认 / 环境探查 + 人确认 / `dify-agent/` 回退读取 / 模板回退（须注明） |
